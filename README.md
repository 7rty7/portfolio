# Portfolio

生成AI（Claude）を活用した、業務自動化と開発のサンプル集です。

| フォルダ | 内容 | 技術 |
|---|---|---|
| [gmail-to-sheet-ai](gmail-to-sheet-ai/) | Gmailの本文と添付PDFからAIで項目を抽出し、スプレッドシートへ自動登録（人の確認・重複防止・エラー時の再実行つき） | Google Apps Script, Claude API |

## 対応できること
- GAS / Python による業務自動化（Gmail・スプレッドシート・Drive・外部API連携）
- 既存コードの調査・不具合修正・リファクタリング
- データ整形・CSV/Excel処理・レポート自動生成
- HTML/CSS/JavaScript・WordPress の実装・修正
