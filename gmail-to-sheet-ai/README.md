# Gmail → AI抽出 → スプレッドシート自動登録（GAS）

メール本文と添付PDFから必要な項目を生成AI（Claude API）で抽出し、Googleスプレッドシートに自動で登録する仕組みです。
物件情報・注文・問い合わせなど、書式が毎回少しずつ違うメールの転記作業をなくすことを想定しています。

## 特長
- **書式の揺れに強い**：決まった位置を読み取る方式ではなく、AIが内容を読んで項目を抽出します
- **人の確認を挟める**：抽出結果は「確認待ち」シートに入り、チェックを入れた行だけが「確定」シートへ移ります
- **重複登録を防止**：処理済みラベルとメッセージIDの二重チェックで、同じメールを二度登録しません
- **エラー時に再実行できる**：失敗したメールには `error` ラベルが付き、`retryErrors()` で再処理できます。内容はログシートに記録されます
- **二重実行を防止**：`LockService` で、同時に実行されないようにしています
- **他の業務に流用しやすい**：抽出項目は `CONFIG.FIELDS` の配列を書き換えるだけで変更できます

## 処理の流れ
```
Gmail（ラベル: ai-import）
  └─ importMails()  … 定期実行（例: 10分ごと）
       ├─ 本文＋PDF添付 → Claude API → JSONで抽出
       ├─ 「確認待ち」シートに追記（チェックボックス付き）
       └─ ラベル: ai-import/done（失敗時は ai-import/error）
人が確認してチェックを入れる
  └─ commitReviewed() → 「確定」シートへ移動
```

## セットアップ
1. スプレッドシートを作成し、[拡張機能] → [Apps Script] に `Code.gs` を貼り付けます
2. [プロジェクトの設定] → スクリプトプロパティに `ANTHROPIC_API_KEY` を登録します
3. Gmailでラベル `ai-import` を作成し、対象メールに自動でこのラベルが付くようフィルタを設定します
4. トリガーを設定します：`importMails` を時間主導で（例: 10分ごと）実行

## 月額費用の目安
- GAS：無料（Google Workspaceの実行時間の上限内で動作）
- Claude API：処理件数に応じた従量課金（メール1通あたりの目安は数円程度。PDFのページ数によって変わります）
